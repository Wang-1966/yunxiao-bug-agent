# 云效 Bug 修复 Agent - 前端

基于 React 18 + TypeScript + Vite + Ant Design 5 构建的前端应用。

## 安装依赖

```bash
npm install
```

## 开发

```bash
npm run dev
```

前端将运行在 http://localhost:3000

## 构建

```bash
npm run build
```

## 功能

- 仪表盘：Bug 统计和 Agent 状态总览
- Bug 列表：查看、筛选、创建和修复 Bug
- Agent 监控：实时查看 Agent 状态和日志
- LLM 配置：管理 LLM 提供商和模型配置

## 技术栈

- React 18
- TypeScript
- Vite
- Ant Design 5
- Zustand (状态管理)
- React Router
- Axios
- WebSocket
